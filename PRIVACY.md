# Dane lokalne

Gra przechowuje postęp, ustawienia, historię wypraw i telemetrię developerską lokalnie. Historię i telemetrię można wyłączyć w ustawieniach. Eksport zapisuje plik na urządzeniu; nie wysyła go automatycznie do autora.

Strona prezentacyjna nie zawiera analityki, reklam, zewnętrznych czcionek ani własnych trackerów. Wybranie linku GitHub przenosi do GitHuba. Hosting GitHub Pages i pobieranie plików podlegają zasadom prywatności GitHuba. Pliki gry mogą zostać pobrane z serwera podczas otwierania wersji Web.
